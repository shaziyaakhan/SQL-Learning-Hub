# SQL-Learning-Hub
A beginner-friendly SQL learning project created by me and my two friends while pursuing our BCS degree. We built this project together as part of our SQL learning journey to organize the queries and concepts we practiced and make them easier for other beginners to understand.

About the Project

We created SQL Learning Hub to bring the SQL queries and concepts we learned into one organized place. It helps beginners explore SQL topics and learn step by step.

Features
- SQL queries organized by topic
- Beginner-friendly learning material
- Examples of SQL concepts and commands

Technologies Used
- HTML
- CSS
- JavaScript

What We Learned
- Writing and understanding SQL queries
- Organizing SQL concepts by topic
- Collaborating on a group project
- Improving our understanding of SQL
